# Delivery checklist

When selling the product, deliver:

- source code
- GitHub repository access
- production environment access
- domain and DNS access
- database backups
- Docker configuration
- environment variables list
- admin demo account
- documentation
- pricing sheet
- onboarding guide
- customer support contact

## Recommended handover files

- `README.md`
- `sales/offer.md`
- `sales/demo-script.md`
- `sales/due-diligence.md`
- `sales/delivery-checklist.md`
