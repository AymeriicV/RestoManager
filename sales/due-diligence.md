# Due diligence checklist

This is the buyer checklist for a software sale.

## Product

- working demo
- feature list
- screenshots
- roadmap

## Technical

- source code ownership
- repo access
- environment variables documented
- deployment instructions
- backups
- database schema
- third-party dependencies

## Business

- pricing model
- target market
- customer acquisition plan
- support model
- churn / retention if available

## Legal

- domain ownership
- trademark / brand usage
- contracts
- privacy policy
- terms of service

## Operational

- admin account for demo
- clean database
- onboarding steps
- support handoff
