# Demo script

Goal: show business value, not code.

## 10-minute flow

1. Login
2. Dashboard
3. Supplier invoice upload and OCR
4. Stock item creation and archive
5. Recipe costing and allergen calculation
6. HACCP / temperatures
7. Planning and time clock
8. Analytics and price alerts

## What to say

- "I know where my money goes."
- "I can trace every invoice."
- "I see stock, costs, and margins in one place."
- "I can prove HACCP controls."
- "I can run the restaurant with fewer Excel files."

## What to avoid

- long technical explanations
- deployment details
- internal code structure
- future features that are not sold yet
